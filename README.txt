walomap Android (WebView) - build with GitHub Actions
1) Create a new GitHub repository (e.g. walomap) and upload ALL files of this folder (keep the folders, including .github/workflows/build.yml).
2) Open the Actions tab -> Build APK -> wait until it finishes (about 3-6 minutes).
3) Download app-debug.apk from Releases (or from the run's Artifacts), install it, allow Location.
